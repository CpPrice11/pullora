## Pullora v5.14.0

Цей реліз спрощує налаштування Pullora й приводить їх до спільного візуального контракту з бібліотекою та сторінкою «Про застосунок».

### Що змінилося

- У Settings залишилися три розділи: «Загальне», «Журнал подій» та «Обслуговування».
- Власника каталогу зафіксовано як `CpPrice11`. Поле для його зміни прибрано.
- Папку встановлення перенесено до «Загальне». Екран показує ефективний стандартний або користувацький шлях і зберігає перевірки безпеки.
- Налаштування фону й підкладок стали компактнішими. Прозорість і розмиття однаково діють у Library, Settings, About та Install.
- Кнопка «Скинути» розміщена внизу навігації. Вона скидає параметри, але не видаляє застосунки, версії, обране, папки чи журнал.
- Журнал подій розділяє час, рівень, джерело, повідомлення й технічні деталі. Довгі шляхи більше не розтягують сторінку.
- «Обслуговування» поділено на сховище й діагностику. Імпорт та експорт бібліотеки прибрано з інтерфейсу.
- Settings використовує ті самі поверхні, грані, фон і сітку, що Library та About, у світлій і темній темах.

### Перевірено

- Frontend build, компонентні перевірки, 867 українських і 867 англійських ключів та 32 WCAG-пари.
- 25 headless UI-перевірок для Library, Install, Settings і About у світлій та темній темах на 1000×700, 1280×720 і 1920×1080.
- Rust formatting, locked checks і 44 тести.
- Production Tauri build, release-check, SHA-256 та smoke-test portable EXE.

Pullora v5.14.0 не використовує Authenticode Code Signing. Цілісність файлів перевіряється через `SHA256SUMS.txt`.

---

This release simplifies Pullora settings and aligns them with the visual contract used by Library and About.

### Changes

- Settings now has three sections: General, Event log, and Maintenance.
- The catalog owner is fixed to `CpPrice11`. The editable owner field has been removed.
- The installation folder now lives in General. The page shows the effective default or custom path and keeps all safety checks.
- Background and surface controls are more compact. Opacity and blur behave consistently across Library, Settings, About, and Install.
- Reset sits at the bottom of the settings navigation. It resets preferences without deleting applications, versions, favorites, folders, or logs.
- The event log separates time, level, source, message, and technical details. Long paths no longer stretch the page.
- Maintenance is split into storage and diagnostics. Library import and export controls have been removed.
- Settings uses the same surfaces, borders, background, and grid as Library and About in both themes.

### Verified

- Frontend build, component checks, 867 Ukrainian and 867 English keys, and 32 WCAG contrast pairs.
- 25 headless UI checks for Library, Install, Settings, and About in both themes at 1000×700, 1280×720, and 1920×1080.
- Rust formatting, locked checks, and 44 tests.
- Production Tauri build, release checks, SHA-256, and a portable EXE smoke test.

Pullora v5.14.0 does not use Authenticode Code Signing. `SHA256SUMS.txt` verifies file integrity.
