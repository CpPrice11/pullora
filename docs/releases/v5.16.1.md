## Pullora v5.16.1

Це безпечний patch-реліз замість відкликаної v5.16.0.

### Що виправлено

- Прибрано PowerShell із `ExecutionPolicy Bypass`, тимчасові `.ps1` і підвищене переміщення файлів.
- Pullora більше не завантажує та не замінює власний EXE. Кнопки версій відкривають відповідний GitHub Release для ручного завантаження.
- Setup/MSI за потреби запитують права адміністратора через стандартний Windows UAC.
- Встановлення у недоступну для запису власну папку завершується зрозумілою помилкою без спроб обійти системні дозволи.
- Збережено компактний центр оновлень та інші зміни v5.16.0.

### Безпека

- v5.16.0 відкликано; її EXE-файли видалено з GitHub.
- Pullora не додає себе до виключень Defender і не вимикає системний захист.
- Нові артефакти проходять окреме сканування Microsoft Defender та перевірку SHA-256 перед публікацією.

Pullora v5.16.1 не має Authenticode-підпису. Перевіряйте завантаження за `SHA256SUMS.txt` із цього ж GitHub Release.

## Pullora v5.16.1

This security patch replaces the withdrawn v5.16.0 release.

### Fixes

- Removed PowerShell with `ExecutionPolicy Bypass`, temporary `.ps1` files, and elevated file moves.
- Pullora no longer downloads or replaces its own EXE. Version actions now open the matching GitHub Release for manual download.
- Setup/MSI packages request elevation through the standard Windows UAC flow when needed.
- Installation to a custom non-writable folder fails clearly without attempting to bypass system permissions.
- The compact update center and the other v5.16.0 improvements remain included.

### Security

- v5.16.0 was withdrawn and its EXE assets were removed from GitHub.
- Pullora does not add Defender exclusions or disable system protection.
- New artifacts receive a separate Microsoft Defender scan and SHA-256 verification before publishing.

Pullora v5.16.1 is not Authenticode-signed. Verify downloads against `SHA256SUMS.txt` from the same GitHub Release.
