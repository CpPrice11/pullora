## Pullora v5.22.0

Цей реліз полірує візуальну частину Pullora без зміни структури та робочої щільності.

### Що змінилося

- Стандартний фон отримав тонку статичну сітку та м'яке світіння. На власних фонових зображеннях сітка прихована.
- У Settings з'явився вибір рівня ефектів: `Вимкнено`, `Збалансовано` або `Посилено`.
- Режим `Вимкнено` прибирає blur і декоративні ефекти, але зберігає вибране значення повзунка розмиття.
- Основні поверхні, підняті меню та діалоги використовують окремі рівні скла, кромок і тіней.
- Фони, сторінки, меню, діалоги, сповіщення, skeleton і progress отримали короткі узгоджені переходи.
- Клавіатурна навігація залишається миттєвою, а `prefers-reduced-motion` прибирає переміщення.

Pullora v5.22.0 не має Authenticode-підпису. Перевіряйте EXE за `SHA256SUMS.txt` із цього ж GitHub Release. Windows SmartScreen може показати попередження для нового unsigned-файлу.

## Pullora v5.22.0

This release polishes Pullora's visuals without changing its structure or workspace density.

### Changes

- The standard background now has a subtle static grid and soft glow. The grid stays hidden on custom background images.
- Settings now offers three effects levels: `Off`, `Balanced`, and `High`.
- `Off` removes blur and decorative effects while preserving the selected blur value.
- Primary surfaces, elevated menus, and dialogs use separate glass, edge, and shadow levels.
- Backgrounds, pages, menus, dialogs, notifications, skeleton states, and progress indicators now use short, consistent transitions.
- Keyboard navigation remains instant, and `prefers-reduced-motion` removes movement.

Pullora v5.22.0 is not Authenticode-signed. Verify the EXE files against `SHA256SUMS.txt` from the same GitHub Release. Windows SmartScreen may warn about a new unsigned file.
