## Pullora v5.18.1

This patch fixes image cropping and makes the Library context menu more compact.

### Fixes

- The crop preview now matches the background's final position and scale.
- Images can be dragged across the full available crop area.
- The crop dialog is larger, and hero backgrounds use the real proportions of normal and compact modes.
- Cover and background actions are grouped into separate submenus.
- Library status values remain readable in the light theme without changing the grid or brand colors.
