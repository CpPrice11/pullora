## Pullora v5.20.0

Цей реліз робить вкладку «Про застосунок» зрозумілим центром стану Pullora та прибирає небезпечне самоновлення portable-версії.

### Що змінилося

- Статус поточної та останньої версій тепер читається одним повідомленням.
- Список релізів краще використовує широкі екрани й лишається компактним на мінімальному розмірі вікна.
- Діалоги оновлення, нотаток релізу та очищення підтримують клавіатуру, повернення фокуса й обидві мови.
- Portable-версія більше не замінює власний EXE: вона відкриває офіційний GitHub Release для ручного завантаження.
- Встановлена версія зберігає Tauri updater із криптографічною перевіркою setup-пакета.

Pullora v5.20.0 не має Authenticode-підпису. Перевіряйте EXE за `SHA256SUMS.txt` із цього ж GitHub Release. Windows SmartScreen може показати попередження для нового unsigned-файлу.

## Pullora v5.20.0

This release turns About into a clear Pullora status hub and removes unsafe portable self-updates.

### Changes

- Current and latest version status is now expressed as one clear message.
- The release list uses wide screens better while staying compact at the minimum window size.
- Update, release notes, and cleanup dialogs support keyboard navigation, focus restoration, and both languages.
- The portable build no longer replaces its own EXE; it opens the official GitHub Release for a manual download.
- Installed builds keep the Tauri updater with cryptographic setup-package verification.

Pullora v5.20.0 is not Authenticode-signed. Verify the EXE files against `SHA256SUMS.txt` from the same GitHub Release. Windows SmartScreen may warn about a new unsigned file.
