## Pullora v5.15.0

Цей реліз спрощує навігацію бібліотеки й виправляє контекстне меню, не змінюючи айдентику Pullora.

### Що змінилося

- У sidebar залишилися три фільтри: «Усі», «Оновлення» та «Встановлені». Обране й далі доступне у власній системній папці.
- «Оновлення» та «Встановлені» мають компактні іконки, а сортування розміщене над пошуком.
- Звичайну й компактну щільність об'єднано в один перемикач «Компактний». Режим зберігається між запусками.
- Контекстне меню картки тепер відкривається як popup поверх Library, а не всередині sidebar.
- Головне меню й підменю папок автоматично змінюють напрямок біля країв вікна та прокручують лише власний довгий список.
- ПКМ, Context Menu, `Shift+F10`, стрілки, `Home`, `End`, `Enter`, `Space` та `Escape` працюють з поверненням фокуса до картки.
- Темна й світла теми, звичайна й компактна щільність використовують однакову геометрію та набір іконок.

### Перевірено

- Frontend build, компонентні, i18n, WCAG і CSS-перевірки.
- Контекстне меню та обидва підменю у двох темах на 1000×700, 1280×720, 1920×1080 і Full HD зі scale 100%/125%.
- Rust formatting, checks, tests, production Tauri build, SHA-256 і smoke-test portable EXE.

Pullora v5.15.0 не використовує Authenticode Code Signing. Цілісність файлів перевіряється через `SHA256SUMS.txt`.

---

This release simplifies Library navigation and fixes the context menu without changing Pullora's identity.

### Changes

- The sidebar now has three filters: All, Updates, and Installed. Favorites remain available in their system folder.
- Updates and Installed use compact icons, and sorting now sits above search.
- Normal and compact density are controlled by one Compact switch. The choice persists between launches.
- A card's context menu now opens as a popup above Library instead of inside the sidebar.
- The root menu and folder submenus flip near window edges and scroll only their own long lists.
- Right-click, Context Menu, `Shift+F10`, arrow keys, `Home`, `End`, `Enter`, `Space`, and `Escape` work with focus returning to the card.
- Dark and light themes, in both normal and compact density, share the same geometry and icon set.

### Verified

- Frontend build, component, i18n, WCAG, and CSS checks.
- The context menu and both submenus in both themes at 1000×700, 1280×720, 1920×1080, and Full HD at 100%/125% scale.
- Rust formatting, checks, tests, production Tauri build, SHA-256, and a portable EXE smoke test.

Pullora v5.15.0 does not use Authenticode Code Signing. `SHA256SUMS.txt` verifies file integrity.
