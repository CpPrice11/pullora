## Pullora v5.18.3

Цей патч об'єднує кадрування всіх зображень в одному редакторі.

### Що виправлено

- Загальний фон, hero-фон і обкладинка тепер кадруються однаково.
- Нерухома рамка одразу показує форму й пропорції майбутнього зображення.
- Зображення можна перетягувати мишею або дотиком до всіх доступних країв.
- Масштаб змінюється повзунком, колесом миші або pinch-жестом.
- Pullora визначає монітор, на якому відкрито вікно, і підлаштовує пропорції загального фону.
- Попередній перегляд hero-фону відповідає результату в бібліотеці.

Pullora v5.18.3 не має Authenticode-підпису. Перевіряйте завантаження за `SHA256SUMS.txt` із цього ж GitHub Release.

## Pullora v5.18.3

This patch brings all image cropping into one editor.

### Fixes

- The global background, hero background, and cover now use the same crop editor.
- A fixed frame shows the final shape and proportions before saving.
- Images can be dragged with a mouse or touch to every available edge.
- Zoom works with the slider, mouse wheel, and pinch gesture.
- Pullora detects the monitor that contains its window and adjusts the global background proportions.
- The hero background preview now matches the result in the Library.

Pullora v5.18.3 is not Authenticode-signed. Verify downloads against `SHA256SUMS.txt` from the same GitHub Release.
