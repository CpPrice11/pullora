## Pullora v5.16.0

Цей реліз робить перевірку та встановлення оновлень компактнішими. У режимі «Оновлення» центр займає верх правої області й не дублює hero-картку та панель запуску.

### Що змінилося

- Режим «Оновлення» показує компактний центр замість hero-картки, панелі запуску й деталей застосунку.
- Статуси «Доступно», «Пропущено» та час останньої перевірки зібрані в одному рядку.
- Portable-оновлення запускаються через чинну чергу з підтвердженням.
- Завершені завантаження можна сховати або показати.
- Помилки, повтор, очищення, запуск і відкриття папки з’являються лише тоді, коли дія доступна.
- Повідомлення про результат винесені у спільне сповіщення Library, тому вони не розтягують центр оновлень.
- Темна й світла теми, звичайна й компактна щільність використовують однакову композицію.
- У Settings і «Про застосунок» прибрано дубльовані сторінкові заголовки.

### Перевірено

- Frontend build, компонентні, i18n, WCAG і CSS-перевірки.
- Темна й світла теми, обидві щільності, стандартний і власний фон на 1000×700, 1280×720 та 1920×1080.
- Керування з клавіатури, `aria-live` і щонайменше чотири видимі рядки на 1000×700.
- Rust formatting, checks, tests, production Tauri build, SHA-256 і smoke-test portable EXE.

Pullora v5.16.0 не використовує Authenticode Code Signing. Цілісність файлів перевіряється через `SHA256SUMS.txt`.

## Pullora v5.16.0

This release makes update checks and installation more compact. In Updates mode, the center occupies the top of the main area without duplicating the hero card or launch panel.

### Changes

- Updates mode shows a compact center instead of the hero card, launch panel, and app details.
- Available, skipped, and last-checked statuses now share one row.
- Portable updates use the existing queue with confirmation.
- Completed downloads can be hidden or shown.
- Error, retry, cleanup, launch, and open-folder actions appear only when available.
- Results use the shared Library notification, so they no longer stretch the update center.
- Dark and light themes, in both normal and compact density, share the same composition.
- Duplicate page headings were removed from Settings and About.

### Verified

- Frontend build, component, i18n, WCAG, and CSS checks.
- Dark and light themes, both densities, and standard and custom backgrounds at 1000×700, 1280×720, and 1920×1080.
- Keyboard navigation, `aria-live`, and at least four visible rows at 1000×700.
- Rust formatting, checks, tests, production Tauri build, SHA-256, and a portable EXE smoke test.

Pullora v5.16.0 does not use Authenticode Code Signing. `SHA256SUMS.txt` verifies file integrity.
