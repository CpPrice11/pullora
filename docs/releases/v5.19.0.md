## Pullora v5.19.0

Цей реліз виправляє контраст інтерфейсу та завершує уніфікацію головних дій.

### Що змінилося

- Дата оновлення, активна версія та мова тепер читабельні у світлій і темній темах.
- Головні дії Library, Install і Confirm використовують одну синю кнопку з білим текстом.
- Стани наведення, натискання, фокуса, завантаження та блокування працюють однаково в обох темах.
- Попередній перегляд власного фону враховує пропорції активного монітора й відповідає вигляду збереженого фону.
- Загальний фон, hero-фон і обкладинка залишаються незалежними та використовують спільний редактор кадрування.

Pullora v5.19.0 не має Authenticode-підпису. Перевіряйте завантаження за `SHA256SUMS.txt` із цього ж GitHub Release.

## Pullora v5.19.0

This release fixes interface contrast and completes the primary action cleanup.

### Changes

- The update date, active version, and language are readable in both light and dark themes.
- Primary actions in Library, Install, and Confirm use the same blue button with white text.
- Hover, active, focus, loading, and disabled states now behave consistently in both themes.
- The custom background preview uses the active monitor ratio and matches the saved background.
- The global background, hero background, and cover remain independent and use the same crop editor.

Pullora v5.19.0 is not Authenticode-signed. Verify downloads against `SHA256SUMS.txt` from the same GitHub Release.
