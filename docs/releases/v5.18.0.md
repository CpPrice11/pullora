## Pullora v5.18.0

Цей реліз додає неруйнівне кадрування фонів і обкладинок.

### Що змінилося

- Загальні фони світлої й темної тем, hero-фон та обкладинка застосунку мають незалежні позицію і масштаб.
- Після вибору зображення Pullora відкриває живий попередній перегляд. Зображення можна перетягувати, масштабувати та скидати до центру.
- Для загального фону доступний перегляд на 1000×700, 1280×720 і 1920×1080. Hero-фон можна перевірити у звичайному та компактному режимах.
- Оригінальний файл не обрізається і не перекодовується. Pullora зберігає лише координати фокуса та масштаб.
- Drag і zoom оновлюються один раз на кадр. Зображення не перечитується під час руху.
- Вікно встановлення зберігає сталий розмір, а кнопки навігації залишаються на одному місці між етапами.

### Перевірено

- Українська й англійська локалізації, клавіатурне керування та доступний focus.
- Темна і світла теми, звичайний і компактний режими, стандартні та власні фони.
- Розміри 1000×700, 1280×720 і 1920×1080, включно з Windows scale 125%.
- Незалежність усіх чотирьох зображень, збереження старих налаштувань і відсутність зміщення сітки.

Pullora v5.18.0 не має Authenticode-підпису. Перевіряйте завантаження за `SHA256SUMS.txt` із цього ж GitHub Release.

## Pullora v5.18.0

This release adds non-destructive cropping for backgrounds and covers.

### Changes

- Light and dark launcher backgrounds, app hero backgrounds, and app covers now keep independent positions and zoom levels.
- Pullora opens a live preview after an image is selected. You can drag, zoom, or reset it to the center.
- Launcher backgrounds can be previewed at 1000×700, 1280×720, and 1920×1080. Hero backgrounds support normal and compact previews.
- The original file is never cropped or re-encoded. Pullora stores only the focus coordinates and zoom.
- Drag and zoom update once per frame. The image is not read again while it moves.
- The install window keeps a stable size, and navigation buttons stay in the same place between steps.

### Verified

- Ukrainian and English localization, keyboard controls, and accessible focus.
- Dark and light themes, normal and compact modes, standard and custom backgrounds.
- 1000×700, 1280×720, and 1920×1080, including Windows scale 125%.
- Independence of all four images, compatibility with existing settings, and no layout shift.

Pullora v5.18.0 is not Authenticode-signed. Verify downloads against `SHA256SUMS.txt` from the same GitHub Release.
