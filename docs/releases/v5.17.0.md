## Pullora v5.17.0

Цей реліз спрощує встановлення застосунків і робить оновлення безпечнішими.

Важливо: перехід із v5.16.1 потрібно виконати вручну, оскільки в ній самооновлення було вимкнено. Після встановлення v5.17.0 наступні оновлення працюватимуть відповідно до portable або встановленого режиму Pullora.

### Що змінилося

- Майстер встановлення став коротшим: прибрано дубльовані етапи, пояснення та статуси.
- Кнопка «Оновити» одразу встановлює точну нову stable-версію через спільну чергу, без ручного вибору релізу й файла.
- Якщо сумісного portable-файла немає, Pullora пропонує відкрити звичайний вибір файла.
- Стандартна та власна папки проходять однакову перевірку. Системні, кореневі й недоступні для запису шляхи блокуються до початку завантаження.
- Незавершене встановлення можна повторити або очистити після перезапуску. Робоча версія залишається активною, доки нова не пройде перевірку запуску.
- Оновлення самої Pullora розрізняє portable та встановлену версію. Portable-файл перевіряється за SHA-256, а встановлена версія використовує підписаний Tauri updater.

### Перевірено

- Українська й англійська локалізації, WCAG-контраст і клавіатурна навігація.
- Темна й світла теми, обидві щільності, стандартний і власний фон на 1000×700, 1280×720 та 1920×1080, включно з масштабом Windows 125%.
- 51 Rust-тест, Clippy, production-збірка, перевірка SHA-256 та smoke-test portable EXE.

Pullora v5.17.0 не має Authenticode-підпису. Перевіряйте завантаження за `SHA256SUMS.txt` із цього ж GitHub Release.

## Pullora v5.17.0

This release simplifies app installation and makes updates safer.

Important: upgrading from v5.16.1 requires a manual download because self-update was disabled in that version. After installing v5.17.0, future updates will follow Pullora's portable or installed mode.

### Changes

- The install wizard is shorter, with duplicate steps, explanations, and statuses removed.
- Update now installs the exact new stable version through the shared queue without asking for a release or file.
- If no compatible portable file exists, Pullora offers the regular file picker.
- Default and custom install folders use the same validation. System folders, drive roots, and non-writable paths are blocked before download.
- Interrupted installs can be retried or cleaned up after restart. The working version stays active until the replacement passes its launch check.
- Pullora detects whether it is portable or installed. Portable updates verify SHA-256, while installed builds use the signed Tauri updater.

### Verified

- Ukrainian and English localization, WCAG contrast, and keyboard navigation.
- Dark and light themes, both densities, standard and custom backgrounds at 1000×700, 1280×720, and 1920×1080, including Windows scale 125%.
- 51 Rust tests, Clippy, production build, SHA-256 verification, and a portable EXE smoke test.

Pullora v5.17.0 is not Authenticode-signed. Verify downloads against `SHA256SUMS.txt` from the same GitHub Release.
