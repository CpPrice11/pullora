## Pullora v5.23.0

### Бібліотека й запуск

- Нові картки застосунків з описом, прямими посиланнями та діями. Додано табличне подання; перемикач з іконками замінює компактний режим і зберігає вибір.
- Прогрес встановлення та відновлення після помилки доступні безпосередньо в картці.
- Меню системного трея дозволяє запускати встановлені програми, показувати й приховувати Pullora та завершувати роботу. Звичайне закриття вікна діє як раніше.
- Warframe Arsenal відкривається як вебсайт через «Відвідати».
- Додано нову іконку Pullora, типові іконки програм і галерею скриншотів із pullora-assets. Власні зображення мають пріоритет.

### Встановлення й оновлення

- Встановлення одним натисканням віддає перевагу portable EXE та повному ZIP. За неоднозначності можна вибрати файл; setup/MSI використовує системний інсталятор.
- Оновлення зберігає поточний тип пакета. Додано перевірку наявності файлів, підключення знайдених Windows-інсталяцій і захист від змін запущеної програми.
- Перед встановленням перевіряється доступна SHA-256. При вичерпанні GitHub API доступний резервний шлях через опублікований маніфест контрольних сум; без нього неперевірені пакети не пропонуються.
- Стандартна папка нових налаштувань: `C:\Program Files\Pullora\Apps`. Збережені шляхи й попередні встановлення не переносяться.

Також впорядковано репозиторій, додано інструкцію підготовки застосунків до оновлень і прибрано невикористані переклади старих екранів.

EXE не мають Authenticode-підпису. Контрольні суми є у `SHA256SUMS.txt`; встановлена Pullora перевіряє підпис Tauri updater. Політика захисту Windows не змінена.

## Pullora v5.23.0

### Library and launch

- New app cards with descriptions, direct links and actions. A persistent icon-only Cards / Table switch replaces compact mode.
- Installation progress and recovery actions are available directly in each card.
- The system tray can launch installed apps, show or hide Pullora, and exit. Closing the window keeps its previous behavior.
- Warframe Arsenal opens as a website through Visit.
- Added the new Pullora icon, default app icons and a screenshot gallery from pullora-assets. Custom images retain priority.

### Installation and updates

- One-click installation prefers portable EXE and complete ZIP packages. Ambiguous files can be selected manually; setup/MSI uses the system installer.
- Updates preserve the current package type. Added file-presence checks, explicit connection of detected Windows installations, and guards for running apps.
- Available SHA-256 checksums are verified before installation. When GitHub API limits are exhausted, the fallback uses published checksum manifests; packages without those checksums are not offered by the fallback.
- New settings default to `C:\Program Files\Pullora\Apps`. Existing paths and installations are preserved.

The repository is organized by purpose, the app update integration guide is included, and unused translations from retired screens are removed.

EXE files are not Authenticode-signed. Use `SHA256SUMS.txt` to verify downloads; installed Pullora verifies Tauri updater signatures. Windows protection policy is unchanged.
