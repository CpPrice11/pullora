## Pullora v5.13.0

Цей реліз додає безпечну стандартну папку для встановлення застосунків.

### Що змінилося

- Звичайна версія Pullora встановлює застосунки в `%LOCALAPPDATA%\Pullora\Apps`. Portable-версія зберігає їх у папці `apps` поруч із лаунчером.
- Наявний користувацький шлях зберігається. Pullora переносить лише порожнє значення або старий автоматичний шлях у «Документах».
- Backend зберігає єдиний ефективний шлях для встановлення, оновлення, rollback, очищення та видалення. Зміна теми або скидання вигляду його не перезаписує.
- Перед завантаженням Pullora перевіряє папку, права запису, блокування, небезпечні junction і вільне місце на диску.
- У Settings шлях доступний лише для читання. Змінити його можна через системний вибір папки.
- Помилки шляху й дискового простору мають українські та англійські повідомлення без технічних деталей файлової системи.

### Перевірено

- Frontend build, компонентний контракт, 870 українських і 870 англійських ключів та 32 WCAG-пари.
- 25 headless UI-перевірок у темній і світлій темах на 1000×700, 1280×720 та 1920×1080.
- Rust formatting, locked checks і 41 тест, включно з міграцією, junction, блокуванням папки та нестачею місця.
- Production Tauri build, release-check, SHA-256 і smoke-test portable EXE.

Pullora v5.13.0 не використовує Authenticode Code Signing. Цілісність файлів перевіряється через `SHA256SUMS.txt`.

---

This release adds a safe default folder for installed applications.

### Changes

- Installed Pullora builds use `%LOCALAPPDATA%\Pullora\Apps`. Portable builds keep applications in an `apps` folder next to the launcher.
- Existing custom paths remain unchanged. Pullora migrates only an empty value or the old automatic path in Documents.
- The backend keeps one effective path for install, update, rollback, cleanup, and uninstall. Theme changes and appearance resets cannot overwrite it.
- Before a download starts, Pullora checks the destination, write access, folder locks, unsafe junctions, and free disk space.
- Settings shows the path as read-only. Users can change it through the system folder picker.
- Path and disk-space errors have Ukrainian and English messages without raw file-system details.

### Verified

- Frontend build, component contract, 870 Ukrainian and 870 English keys, and 32 WCAG contrast pairs.
- 25 headless UI checks in dark and light themes at 1000×700, 1280×720, and 1920×1080.
- Rust formatting, locked checks, and 41 tests covering migration, junctions, folder locks, and low disk space.
- Production Tauri build, release checks, SHA-256, and a portable EXE smoke test.

Pullora v5.13.0 does not use Authenticode Code Signing. `SHA256SUMS.txt` verifies file integrity.
