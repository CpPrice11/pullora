## Pullora v5.22.1

Цей patch-реліз виправляє ручне оновлення Library після публікації нових GitHub Releases.

### Що змінилося

- У Library додано постійну кнопку оновлення біля пошуку.
- Ручне оновлення очищає кеш GitHub repositories і releases, повторно завантажує бібліотеку та перевіряє нові версії.
- Виправлено передачу `forceRefresh` до backend-запиту releases, тому новий реліз більше не приховується за старим кешем.
- Кнопка має локалізовані стани, індикатор виконання та повідомлення про завершення.

Pullora v5.22.1 не має Authenticode-підпису. Перевіряйте EXE за `SHA256SUMS.txt` із цього ж GitHub Release. Windows SmartScreen може показати попередження для нового unsigned-файлу.

## Pullora v5.22.1

This patch release fixes manual Library refresh after new GitHub Releases are published.

### Changes

- Library now has a persistent refresh button beside search.
- Manual refresh clears cached GitHub repositories and releases, reloads the Library, and checks for new versions.
- `forceRefresh` now reaches the backend release request, so a new release is no longer hidden by stale cache data.
- The button includes localized states, a progress indicator, and completion feedback.

Pullora v5.22.1 is not Authenticode-signed. Verify the EXE files against `SHA256SUMS.txt` from the same GitHub Release. Windows SmartScreen may warn about a new unsigned file.
