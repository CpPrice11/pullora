## Pullora v5.24.0

- Додано сповіщення Windows про нові стабільні версії встановлених програм. Перевірка працює кожні 30 хвилин, поки запущена Pullora; той самий реліз не сповіщається повторно. Сповіщення можна вимкнути в налаштуваннях.
- У картках і таблиці показується фактична дата релізу. Якщо дата невідома, вона не підміняється датою зміни репозиторію.
- Додано кнопки паузи й продовження завантаження. Докачування використовує підтримку сервера й перевірку незмінності файла; за відсутності підтримки завантаження безпечно починається заново. Після перезапуску Pullora незавершені операції повторюються звичайним способом.
- Відновлено власні фони в картках і таблиці. Кадрування враховує розміри відповідної поверхні; іконки зберігаються незалежно.
- Хрестик вікна ховає Pullora в трей; пункт «Вийти» повністю завершує програму.

Налаштування, попередні встановлення та вибрані папки зберігаються. Політику unsigned EXE й підпис Tauri updater не змінено. Windows може приглушувати сповіщення відповідно до системних налаштувань.

## Pullora v5.24.0

- Added Windows notifications for new stable versions of installed apps. Checks run every 30 minutes while Pullora is running, remember notified releases, and can be disabled in Settings.
- Cards and the table show the actual release date. Unknown dates are never replaced with repository-update timestamps.
- Added download pause and resume. Resuming uses server support and entity validation; unsupported downloads restart safely. Restarting Pullora retains the existing interrupted-operation retry flow.
- Restored custom backgrounds in cards and table rows. Cropping follows the target surface dimensions, independently of app icons.
- Closing the window hides Pullora in the tray; Exit fully closes the application.

Existing settings, installations, and selected folders are preserved. The unsigned EXE policy and Tauri updater signature remain unchanged. Windows may silence notifications according to system settings.
