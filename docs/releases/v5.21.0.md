## Pullora v5.21.0

Цей реліз завершує UI hardening: робить редактор загального фону точнішим і закріплює візуальну стабільність автоматичними перевірками.

### Що змінилося

- Попередній перегляд загального фону тепер відповідає реальному вікну Pullora та має пресети `1000×700`, `1280×720` і `1920×1080`.
- Власний фон став чіткішим, а його прозорість автоматично підлаштовується до світлої та темної тем.
- Виправлено контраст важливого тексту й статусів у світлій та темній темах, зокрема на власних фонах.
- Невеликі функціональні підписи стали читабельнішими без зміни геометрії екранів.
- Меню, діалоги та сповіщення використовують узгоджені рівні накладання зі збереженою клавіатурною навігацією та поведінкою фокуса.

Pullora v5.21.0 не має Authenticode-підпису. Перевіряйте EXE за `SHA256SUMS.txt` із цього ж GitHub Release. Windows SmartScreen може показати попередження для нового unsigned-файлу.

## Pullora v5.21.0

This release completes the UI hardening work: it makes the global background editor more accurate and locks in visual stability with automated checks.

### Changes

- The global background preview now matches the real Pullora window and includes `1000×700`, `1280×720`, and `1920×1080` presets.
- Custom backgrounds are sharper, with opacity that adapts automatically to light and dark themes.
- Contrast is corrected for important text and statuses in both themes, including custom-background states.
- Small functional labels are easier to read without changing screen geometry.
- Menus, dialogs, and notifications use consistent overlay levels while preserving keyboard navigation and focus behavior.

Pullora v5.21.0 is not Authenticode-signed. Verify the EXE files against `SHA256SUMS.txt` from the same GitHub Release. Windows SmartScreen may warn about a new unsigned file.
